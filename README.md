# JEKPE

Турнирная платформа для единоборств · Жекпе-жек турнир платформасы · Tournament platform for combat sports (RU / KZ / EN)

## Файлы
- `index.html` — сайт (лендинг, турниры, тарифы на кредитах)
- `scoreboard.html` — офлайн-табло: BJJ, дзюдо, вольная и греко-римская борьба, самбо, каратэ WKF
- `supabase/schema.sql` — база данных MVP (пользователи, турниры, категории, заявки, кредиты, схватки)

## Кредиты
1 кредит = 1 подтверждённая регистрация. Пакеты: 10 = 5 000 ₸, 100 = 45 000 ₸, 500 = 200 000 ₸.
На старте кредиты начисляет админ вручную (`add_credits`), онлайн-оплата — позже.

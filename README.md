# JEKPE

Турнирная платформа для единоборств · Жекпе-жек турнир платформасы · Tournament platform for combat sports (RU / KZ / EN)

## Файлы
- `index.html` — сайт (лендинг, турниры, тарифы на кредитах)
- `scoreboard.html` — офлайн-табло: BJJ, дзюдо, вольная и греко-римская борьба, самбо, каратэ WKF
- `supabase/schema.sql` — база данных MVP (пользователи, турниры, категории, заявки, кредиты, схватки)

## Кредиты
1 кредит = 1 подтверждённая регистрация. Пакеты: 10 = 5 000 ₸, 100 = 45 000 ₸, 500 = 200 000 ₸.
На старте кредиты начисляет админ вручную (`add_credits`), онлайн-оплата — позже.

## Кабинеты (`app.html`)
- `#events`, `#event-<id>` — публичные турниры и заявка атлета
- `#my` — мои заявки (атлет)
- `#org`, `#manage-<id>` — кабинет организатора: кредиты, турниры, категории, подтверждение заявок
- `#admin` — админка: роли и ручное начисление кредитов

## База
1. `supabase/schema.sql` 2. `supabase/002_privacy.sql` 3. `supabase/003_brackets.sql` 4. `supabase/004_profiles_results.sql`



## Профиль атлета и результаты (как в Smoothcomp)
- `#profile` — свой профиль: дата рождения, пол, пояс (понизить нельзя), вес, клуб
- `#athlete-<id>` — публичный профиль: турниры, схватки, победы/поражения, % побед, победы по способу, медали, история, пояса
- Дисциплины турнира (events.entries): категории создаются автоматически при регистрации (`register_athlete`)
- Ввод результата в сетке (`set_match_result`): победитель проходит дальше, бронза, места 1–3
- Джиу-джитсу по умолчанию — JJIF (веса, возрасты U10–Masters, детские пояса, golden score)
